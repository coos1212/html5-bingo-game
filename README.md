# HTML5 Bingo Game

An interactive HTML5 bingo game built with vanilla JavaScript, CSS3, and HTML5. Play bingo online with dynamic board generation and real-time gameplay.

## Features

✨ **Interactive Gameplay**
- Dynamic 5x5 bingo board with random number generation
- Free space in the center
- Click to mark/unmark cells
- Automatic number calling system

🎮 **Game Mechanics**
- Proper bingo number ranges (B: 1-15, I: 16-30, N: 31-45, G: 46-60, O: 61-75)
- Win detection for:
  - Rows
  - Columns
  - Both diagonals
- Tracks called numbers with visual badges

🎨 **Modern UI**
- Responsive design for desktop and mobile
- Smooth animations and transitions
- Gradient backgrounds and modern styling
- Visual feedback for interactions

🔧 **Controls**
- **New Game** - Start a fresh game with a new board
- **Reset Board** - Clear all marks and start over
- **Call Number** - Draw the next random number
- **Click Cells** - Manually mark/unmark numbers (optional)

## How to Play

1. Open `index.html` in your web browser
2. Click "New Game" to generate a bingo board
3. Click "Call Number" to draw numbers
4. Watch as numbers are automatically marked on the board
5. Alternatively, click cells manually to mark them
6. First to complete a line (row, column, or diagonal) wins!
7. The game will announce when you get BINGO!
8. Click "New Game" to play again
